# «Установка» — тактические презентации

Приложение для футбольных схем и анимации: расставить игроков, нарисовать стрелки и зоны, собрать
презентацию по шагам и показать команде с телефона, ноутбука или телевизора.

## Как устроено

Исходники разбиты на модули, а сборщик склеивает их в **один** HTML-файл — чтобы готовую
презентацию можно было открыть с диска и отправить одним файлом.

```
src/
  index.html          каркас страницы с метками {{CSS_ENGINE}}, {{CSS_APP}}, {{JS_ENGINE}}, {{JS_APP}}
  build.json          порядок модулей и обёртки скриптов
  styles/
    engine.css        стили показа (попадают и в экспортированные презентации)
    app.css           стили редактора
  engine/             движок: модель, геометрия поля, отрисовка, анимация, режим показа
    00-utils.js       мелкие помощники и математика кривых
    05-timing.js      очерёдность движений внутри шага
    10-formats.js     форматы полей (5×5 … 11×11), размеры в метрах, настройки по умолчанию
    15-model.js       проверка и починка данных презентации
    20-markup.js      разметка текста слайдов
    25-geometry.js    перевод координат и отрисовка поля
    30-entities.js    фишки игроков и инвентаря, легенда
    40-board.js       класс Board: кадры, анимация, стрелки, зоны, реплики
    50-presentation.js режим показа со слайдами
    90-exports.js     что движок отдаёт наружу (window.TE)
  app/                редактор
    00-dom.js         помощники разметки, кнопки, значки
    05-storage.js     хранилище презентаций
    10-state.js       состояние редактора и выделение
    15-formations.js  расстановки, наборы стрелок, макеты
    20-sample.js      пример «Маятник»
    25-history.js     правки, отмена, автосохранение
    30-home.js        главный экран
    35-editor-shell.js каркас редактора и список слайдов
    40-tools.js       инструменты и добавление объектов
    45-timeline.js    лента шагов
    50-chapters.js    главы, в том числе зеркальные
    55-playback.js    прокрутка, скорость, работа с несколькими шагами
    60-canvas.js      поле в редакторе, масштаб и сдвиг
    65-overlay.js     подсветка, призраки, направляющие, линейка
    70-pointer-down.js начало касания: выделение, рамка, перетаскивание
    75-clipboard.js   буфер обмена, меню, панель действий
    80-pointer-up.js  завершение касания и инструменты рисования
    85-forms.js       поля ввода панели свойств
    90-inspector.js   панель свойств
    95-objects.js     операции над объектами
    100-text-layout.js вкладки «Текст» и «Макет»
    105-dialogs.js    окна: расстановка, настройки
    106-custom.js     своё: форматы поля, типы стрелок, расстановки, цвета, оформление, эмблема
    110-export.js     показ, экспорт, импорт
    112-video.js      ролик со схемой: видео и GIF своими силами
    113-backup.js     резервная копия всех презентаций и возврат из неё
    114-versions.js   история версий презентации
    115-keys.js       горячие клавиши и справка по ним
    120-site.js       работа сайтом: установка, офлайн, ссылки на показ
    125-reliability.js сохранение при уходе, конфликт вкладок
    130-boot.js       запуск
  site/               файлы для хостинга: манифест, офлайн-режим, иконки
```

## Команды

```
npm run build     собрать dist/ustanovka.html и dist/site/
npm test          пересобрать и прогнать все тесты
```

Результат сборки:

- `dist/ustanovka.html` — то самое приложение одним файлом: открывается с диска, работает без интернета.
- `dist/site/` — то же самое плюс манифест, офлайн-режим и иконки для выкладывания на хостинг.

Править нужно **только** файлы в `src/`: `dist/` перезаписывается сборкой и в репозиторий не попадает.

## Сайт

Каждый пуш в `main` собирает приложение и выкладывает его на GitHub Pages (`.github/workflows/pages.yml`):

- приложение: https://keavors.github.io/FootballSchemes/
- то же одним файлом: https://keavors.github.io/FootballSchemes/ustanovka.html

## Тесты

Тесты гоняют настоящее приложение в безоконном браузере (jsdom): открывают редактор, перетаскивают
игроков, рисуют стрелки, копируют и вставляют, проигрывают анимацию, проверяют показ и экспорт.
Файлы — `tests/*.test.js`, запуск всех — `npm test`.
